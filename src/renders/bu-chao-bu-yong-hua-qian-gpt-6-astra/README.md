# 街角有绝活

《不潮不用花钱》全新 GPT-6 Astra 实现，纯 SVG 城市插画。共享 MP3 与逐词 JSON 直接引用，不下载、不重新识别、不修改歌词时间。

美术以日常物件变成乐器为线索，从午后音乐店走向夜晚屋顶。墨蓝 #203A54、孔雀绿 #0E766E、朱红 #BB3F3C、琥珀黄 #F2BC4B、雾蓝 #AACACD 与纸白 #F3F0E8 是核心颜色。中文原文参考现有 GPT-5.6 实现，使用 Noto Sans CJK SC Medium 正体；工作区没有独立标为 Sol 的目录。英文保留 Barlow Semi Condensed，中文译文使用寒蝉全圆体。字体沿用共享文件，来源与许可仍保存在歌曲字体目录。

frontend-design 的主题与二次审视用于组织完整场景，UI/UX Pro Max 的对比度、留白、运动连续性用于阅读检查。检索到的网页模板不适用于本片，没有套用。每个场景独立绘制；只复用金属、木材、网格等基础材质和基础器物，场景主体、构图及动作不重复。

原文按已有逐词单位从左向右进入，整句先测量并固定位置。字体不倾斜、不拉伸、不旋转，以颜色、自然字号和短位移强调。承载面按首字时间约 260ms 显现，文字快速可读，随后稳定；双语和承载面分层绘制。第二句推动景物新状态。镜头、循环和过渡仅由 Remotion 帧时间驱动，SVG 引用按镜头隔离。画面不出现人物、手臂、手掌或穿鞋的腿脚；动作由可见机械结构或自然环境承担。桌面、器物与支撑面使用统一投影坐标，避免各自倾斜造成悬空与穿插。

使用根目录统一环境，运行 `npm run render:bu-chao-bu-yong-hua-qian:gpt-6-astra`。成片为 `out/不潮不用花钱（GPT-6 Astra）.mp4`，1920×1080、60fps。临时检查只放入 `.work/bu-chao-gpt-6-astra/`。不保留本模型的旧实现，不改动其他模型或共享音频歌词。

全曲包含 31 个独立场景，片头信息分批出现后共同保留。`node scripts/bu-chao-bu-yong-hua-qian/inspect-astra.mjs` 检查实际渲染中的文字边界、静态配色、文字稳定性和 SVG 引用隔离。已通过本实现的 ESLint、类型检查及代表片段导出。按用户要求直接复用歌曲与歌词，不重新识别、校时或核验输入，也不执行全片解码和异常帧扫描。
