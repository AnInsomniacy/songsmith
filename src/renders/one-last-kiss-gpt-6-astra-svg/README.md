# 把最后一次，留在光里

这是独立的纯 SVG 版本，未修改摄影版。复用当前歌曲公共音频与原生 KRC JSON；45 行、382 个演唱及排版单位保留原始毫秒起止时间，日文按原生单位、英文按原生单词出现，中文按对应句出现。平台数据核对与人工对听分开记录，不宣称人工对听已完成。

Frontend-design 的主体导向用于完整的记忆场景。24 幅背景与片头全部重绘：展厅墙裙、雕花画框与肖像，带摆锤的机械钟，记忆档案柜与相片晾线，带光学镀膜和皮革纹理的相机，真实卷盘结构的放映机，窗边双杯、金缮瓷器、暗房显影、花园拱桥、海边站台、钟楼、日晷、纸灯与观星台。细节表达材质和生活痕迹，保留光从物件之间延伸的记忆点。UI/UX 搜索的网页模板未采用，仅应用阅读层级、预留空间与运动连续性；二次审视修正植物连接与前后景关系，避免用数量代替构图。

暮蓝 #172D46、雾紫 #716785、玻璃青 #8DC8CD、杏光 #F4C7A4、珊瑚 #D67D87、月白 #EDF3EF。日文 Klee One 600，英文 Manrope 500，中文 LXGW WenKai TC 400，片头信息 Zen Kaku Gothic New 400。新增字体通过 Google Fonts 取得所需字形，OFL 许可位于公共 fonts/svg；不替换其他版本字体。

24 个独立歌词场景文件和专属片头。结构、木纹、金属反射、玻璃、光束、倒影与景深全由 SVG 绘制，无摄影、生成图、视频背景或第三方视觉实现。只共享材质和有复用价值的物件绘制能力，每页独立构图。第二句通过平滑状态推进同场景，循环用连续周期函数，旋转有连续角速度。背景在下一组原生起点交接 600ms，不缩短歌曲时间。歌词、译文、字体及固定预测量槽位保持不变，入场后停止运动，不按音量改变。

使用共享环境运行 `npm run render:one-last-kiss:gpt-6-astra-svg`。成片 `out/One Last Kiss（GPT-6 Astra · SVG）.mp4`，1920×1080、60fps、15122帧。本版验证与临时文件只放入 `.work/one-last-kiss-svg`。
