# Memories without ownership

A lyric film built around darkroom processes, photographs, drawers, water, and departing objects. Individual scene modules express the changing ownership of memory. Each scene's second-line development is separate from its base drawing, with camera settings grouped beside the evolution modules.

Chinese text uses local LXGW WenKai and Noto Sans CJK SC. Barlow carries Latin text and utility labels. All fonts are loaded before export; text entrances preserve upright glyphs and stable baselines. The shared song data retains the original KRC and 50 vocal lines with source-linked units.

Video.tsx is the entry, storyboard.ts groups lines, typography.ts defines fonts, and scenes contains the drawings and their evolving states. Run `npm run "render:我的回忆不是我的:gpt-5-6"`. Output is `out/我的回忆不是我的（GPT-5.6）.mp4`, at 1920 × 1080 and 60 fps. Prior exports remain available for comparison; the local upright font replacement intentionally changes some glyph shapes and widths.
